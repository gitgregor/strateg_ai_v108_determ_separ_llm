Szybki Start w 3 Krokach

Uruchom kompletne środowisko na Pythonie 3.13 z menedżerem uv w mniej niż minutę.

Krok 1: Klonowanie repozytorium GitHub Git
git clone https://github.com/gitgregor/strateg_ai_v108_determ_separ_llm.git && cd strateg_ai_v108_determ_separ_llm
Krok 2: Instalacja środowiska przez uv (Python 3.13) PowerShell / Bash
uv venv --python 3.13 && .\setup_env.ps1
Krok 3: Uruchomienie aplikacji i kokpitu FastAPI
python main.py
Aplikacja natychmiast uruchamia się pod adresem: http://localhost:8000/app
